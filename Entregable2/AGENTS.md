# Guía del proyecto

- Mantener la lógica de interacción dentro de módulos JavaScript separados por sección o componente; el HTML solo estructura el contenido.
- Mantener los estilos en hojas CSS modulares correspondientes a cada componente o sección. Si un componente necesita estilos en varios documentos o contextos, crear o cargar una hoja adecuada para cada contexto.
- Al cambiar un comportamiento, verificar que su JavaScript y su CSS asociados sigan conectados desde el HTML correspondiente y comprobar la interacción en el navegador.
